**Supporting materials for manuscript: "Trophic status modulates prokaryotic cross-biome life-history strategies"**
===


**Files:**
---

**genome dereplication:** reports of genome dereplication using dRep.


**source data:** data for the present study are provided in this manuscript, with additional source data supplied in the supplementary material.

**Codes:**
---

**metawrap.sh:** MetaWRAP assembles reads into contigs, and subsequently bins the contigs into metagenome-assembled genomes (MAGs).

**dRep.sh:** genome dereplication using dRep.

**Eukrep.sh:** identify eukaryotic contigs.

**VIBRANT.sh:** identify viral contigs.

**AGS_calculation.sh:** determine average genome size (AGS) based on assembled contigs (prokaryotic contigs).

**KEGG_pathway_enrichment.R:** R script for KEGG pathway enrichment analysis based on abundance differential KOs.

**get_PTM.py:** extract potentially transferable metabolites (modified based on https://github.com/mgtools/PhyloMint/blob/master/lib/BuildGraphNetX.py).


**Raw data:**
---
Raw metagenomic sequencing data from the AS microcosm experiment were deposited in NCBI BioProject under accession number PRJNA1455995. Raw metabolomics data for the AS microcosm experiment are available at figshare (https://doi.org/10.6084/m9.figshare.34355151).
